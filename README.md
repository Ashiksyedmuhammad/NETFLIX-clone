A React + Vite clone of Netflix, emulating core streaming platform features, modular UI, and modern authentication using Firebase. The project is designed for learning front-end architecture, state management, and integration with real APIs for scalable, maintainable web apps.

Features
Browse Movies: Explore and display movie posters, details (add real APIs for more content)

User Authentication: Login/signup, powered by Firebase + react-firebase-hooks.

Navigation: Seamless SPA page transitions via React Router

Responsive UI: Netflix-style look with modern CSS

Toast Notifications: Feedback for user actions using react-toastify

Tech Stack
Frontend: React 19, Vite, React Router, Tailwind CSS or custom CSS

Auth & Data: Firebase, react-firebase-hooks

Other Tools: ESLint, react-toastify
